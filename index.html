FLEXBOX

O Flexbox é um modelo de layout unidimensional que permite organizar elementos em uma única linha ou coluna, facilitando o alinhamento, a distribuição de espaço e a adaptação a diferentes tamanhos de tela. Ele é amplamente utilizado no desenvolvimento web para criar layouts responsivos e flexíveis.

Flex Container e Flex Items

O elemento que recebe display: flex se torna um Flex Container. Seus filhos diretos passam a ser Flex Items.

flex-direction

Define a direção em que os Flex Items são organizados dentro do container.

Valores: row, column, row-reverse e column-reverse.

justify-content

Controla como os elementos são distribuídos ao longo do eixo principal.

Exemplos: flex-start, center, flex-end e space-between.

align-items

Controla o alinhamento dos elementos no eixo transversal.

Exemplos: stretch, flex-start, center e flex-end.

flex-wrap

Define se os elementos devem permanecer em uma única linha ou quebrar para uma nova linha quando não houver espaço.

Valores: nowrap, wrap e wrap-reverse.

flex

É um atalho para definir o crescimento, a redução e o tamanho inicial de um Flex Item.

Exemplo: flex: 1 1 280px.
